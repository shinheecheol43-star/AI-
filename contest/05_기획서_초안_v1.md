## 1쪽. 배경과 핵심 아이디어

### 1. 내가 겪은 일
주식을 시작하고 얼마 되지 않아, 바이오와 AI가 결합된 섹터를 골라 **100%가 넘는 수익**을 냈다. 하지만 지금 돌아보면 깊은 분석 없이 얻은 **초심자의 행운**이었다.
문제는 그다음이었다. "나는 섹터를 잘 고른다"는 생각에 다음 섹터를 고르고, **아무 계획 없이 큰 비중**을 넣었다. 주가가 떨어지자 "계속 오를 것"이라는 생각으로 **물타기**를 했고, 결국 **앞서 번 수익을 모두 돌려줬다.**
그때 나에게 없었던 것은 정보가 아니었다. **"이 주식을 얼마나 가져갈지, 얼마나 떨어지면 어떻게 할지"라는 계획**이었다.

### 2. 손님의 불편과 위험 — 입문자가 반복하는 4가지 패턴
1. **스타일 없는 매수**: 단기·스윙·장기의 차이를 모른 채 산다.
2. **수익 뒤의 과신**: 한 번 크게 벌면 다음 매수에 분석 없이 큰 비중을 싣는다.
3. **계획 없는 물타기**: 손실을 빨리 메우려 추가 매수하고, 한 종목에 자산이 쏠린다.
4. **단기가 장기로 굳음**: "며칠만"이던 매매가 물려서 몇 달짜리 보유가 된다.
→ 결과: **상승장에서 번 수익을 급락장에서 돌려주고**, 크게 잃은 입문자는 시장과 앱을 떠난다. [근거 통계 1개 추가 필요: 개인투자자 손실/이탈 관련 공신력 있는 자료]

### 3. 기회 발견 — 도구는 있는데, 쓰는 법이 없다
- 손절·익절을 자동으로 해주는 **자동감시주문**은 이미 대부분의 MTS에 있다. 하지만 입문자는 **"몇 %로 정해야 하는지"** 모르고, 메뉴를 찾기도 어렵다.
- 업계에는 위험 패턴을 감지해 **경고 문구**를 띄우는 기능도 생겼다(예: 타사 '안전 투자 알림'). 하지만 경고만 있고 **"그럼 어떻게 하면 되는지"**는 없다.
- 하나증권V에는 이미 **간편모드, AI 브리핑, 공포탐욕시그널** 등 입문자를 위한 재료가 있다. 빠진 것은 **매수 순간의 '내 계획'**이다.

### 4. 핵심 아이디어
> **매수할 때 "이번 매수는 단기·스윙·장기 중 무엇인가요?"를 묻고, 그 스타일에 맞는 전문가들의 리스크 관리 원칙을 예시로 보여줘 손님이 직접 '내 매매 플랜'을 세우게 한다. 이후 손님이 정한 원칙을 지키도록 보유 중·추가 매수 순간에 다시 꺼내 보여준다.**
> 증권사가 대신 관리하지 않는다. **결정은 손님이, 앱은 손님의 약속을 기억할 뿐이다.**

## 2쪽. 구체화와 실행

### 1. 서비스 구성 (신청자 한정)
| 단계 | 내용 |
|---|---|
| ① 신청 | 하나증권V 간편모드 사용자에게 먼저 제안, 원하는 사람만 켬 |
| ② 스타일 선택 | 매수 시 [단기] [스윙] [장기] [잘 모르겠어요] 선택 |
| ③ 스타일 카드 | 한 줄 요약(예: 단기 "며칠 안에 정리, 빠른 손절이 핵심") + 자세히 보기 |
| ④ 내 매매 플랜 | 스타일별 원칙 예시 제시 → 손절선·목표·보유 기간·비중을 **손님이 직접** 설정 → 자동감시주문 설정을 원클릭 제안 |
| ⑤ 플랜 지킴이 | 손절선 근접 시 "**당신이 정한 원칙**: -5%면 정리. 지금 -4.6%" / **스타일 이탈 감지**: "단기로 샀는데 2주째 보유 중이에요. 플랜을 다시 볼까요?" |
| ⑥ ⭐ 물타기 가드 | 손실 중 추가 매수 시 "처음 플랜에 있던 분할 매수인가요?" → 아니라면 내 돈 기준 카드 표시 |
| ⑦ 복기 | 매도 후 "원칙을 지켰나요?" 기록 → 월간 투자습관 리포트 |

### 2. ⭐ 물타기 가드 상세
계획에 없던 추가 매수일 때 **사실과 계산만** 보여준다.
- 처음 계획: "단기, -3%면 정리 → 지금 -12%"
- 물타기 후: 평균 단가 [ ]원 → [ ]원, 이 종목 비중 30% → 55%
- 원금 회복에 필요한 상승률: -10% → +11.1%, -20% → +25%, -30% → +42.9%, -50% → +100%
- 선택: [플랜을 스윙/장기로 바꾸고 진행] [그대로 진행] [취소] [**내일 다시 생각하기**]
→ "단기 → 물타기 → 강제 장기"로 굳어지는 흐름을 **물타기 순간에 끊는다.**

### 3. 손님 경험의 변화
| 지금 | 바뀐 뒤 |
|---|---|
| 아무 생각 없이 매수 버튼 | 3초 만에 "이번 매매는 단기"라고 스스로 정함 |
| 손절 기준 없음, 자동감시주문 안 씀 | 내가 정한 기준이 자동감시주문으로 연결 |
| 떨어지면 감으로 물타기 | 물타기 전에 내 계획과 내 돈 기준 숫자를 봄 |
| 단타가 물려서 몇 달 방치 | 스타일 이탈 알림으로 계획을 다시 점검 |
| 결과만 기억 | 원칙 준수 기록으로 습관이 쌓임 |

### 4. 실행 방안
- **1단계 (시범 운영, 3개월)**: 간편모드 신규·입문 고객 중 신청자 대상. ②④⑥ 핵심 기능만 적용.
- **2단계 (확대)**: 효과 검증 후 전체 고객 신청 가능, ⑤⑦ 추가.
- **활용할 기존 자산**: 하나증권V 간편모드(진입 화면), 자동감시주문(플랜 실행), AI 기술(카드 문장 생성·요약), 하나Q(원칙 관련 질문 응답).
- **운영 원칙**: 특정 종목 매수·매도 의견 제시 금지, 원칙은 일반 교육 콘텐츠로 준법 검수, 숫자는 손님이 직접 입력.

## 3쪽. 기대효과와 실현 가능성

### 1. 기대효과
**손님**
- 큰 손실 예방, 특히 "수익 반납"과 "계획 없는 물타기" 감소
- 매매 스타일과 리스크 관리 습관을 실전에서 배움
- "앱이 나를 챙겨준다"는 신뢰

**회사**
- **입문자 이탈 방지**: 크게 잃고 떠나는 손님을 지켜 장기 고객으로 육성
- **미래의 WM 손님 확보**: 하나증권의 성장 축인 자산관리(연금·ISA 등)로 이어질 고객층
- **소비자보호 강화**: 불완전판매 등 소비자보호 이슈에 대응하는 선제적 보호 서비스
- **낮은 개발 부담**: 새 시스템이 아니라 기존 기능을 연결하는 구조

**측정 지표**: 플랜 설정률, 원칙 준수율, 물타기 가드 후 주문 변경률, 신청자 vs 비신청자 **6개월 잔존율·예탁자산 증가율·큰 손실(-30%↑) 경험 비율**

### 2. 실현 가능성 — 제약 및 고려사항
| 고려사항 | 대응 |
|---|---|
| **"거래가 줄면 수수료 수익이 줄지 않나?"** | 계획된 매매(분할 매수·손절·익절)는 오히려 매매로 이어짐. 멈추는 것은 계획 없는 충동 매매뿐. 단기 감소 가능성은 인정하되, 이탈 방지와 장기 고객 가치가 더 큼 → **신청자 한정 시범 운영으로 검증** |
| 투자권유 논란 | 종목 의견 없음, 사실·계산·손님 설정만 표시 |
| 알림 피로 | 신청자만, 빈도 제한, 언제든 끄기 |
| 원칙 예시의 정확성 | 투자 교육 자료 기반, 준법 검수, "예시이며 결정은 본인" 고지 |
