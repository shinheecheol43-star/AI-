# 주제 1 아이디어 다듬기 — "매매 스타일별 원칙 코치" (가칭, 이름은 직접 결정)

> **핵심 발상 (본인, 2026-11-11)**: 처음 투자하는 사람은 단기·스윙·장기 매매의 차이를 모르고 투기적으로 거래한다. 상승장에선 벌지만 급락장에서 리스크 관리를 못 해 원금으로 돌아가거나 더 잃는다. → 신청자에 한해, 증권사가 대신 관리하는 게 아니라, **매수할 때 매매 스타일을 고르면 그 스타일의 특성과 전문가들이 쓰는 리스크 관리 원칙을 예시로 알려주는 기능.**
>
> 아래는 이 발상을 Claude와 함께 **구조화·다듬은 것** (기획서 AI 활용 표시 대상: "아이디어 구조화·문장 다듬기·자료 조사").

## 1. 문제 정의 (1쪽 재료)
- **누가**: 주식을 처음 시작한 20대·사회초년생 투자 입문자
- **언제**: 매수 버튼을 누를 때 — "이걸 며칠 갖고 있을지, 얼마 떨어지면 어떻게 할지" 생각 없이 산다
- **결과**:
  1. 상승장에서 번 수익을 급락장에서 반납 → 원금 복귀 또는 손실
  2. **"단타로 샀다가 물려서 장기투자가 되는"** 현상 (스타일 이탈)
- **왜**: 손절·익절 도구(자동감시주문 등)는 이미 있지만 → **언제·얼마로 써야 하는지 모름**, 메뉴도 찾기 어려움
  - 근거: 신규 투자자는 MTS의 많은 정보 중 원하는 걸 찾고 이해하는 데 어려움 (기사)
  - 근거(필요): 본인/주변 경험, 개인투자자 손실 통계 → **추가 확보 필요**

## 2. 기존 서비스와 차이 (참신성)
| 이미 있는 것 | 하는 일 | 빠진 것 |
|---|---|---|
| 자동감시주문 / 스탑로스 (업계 공통) | 정해둔 가격에 자동 매도 | **"얼마로 정해야 하는지"** 안 알려줌 → 초보는 안 씀 |
| 하나증권 공포탐욕시그널 | 종목·업종 투자심리 점수 | 시장 분석. **내 매매 계획**과 연결 없음 |
| 하나증권 ETF MBTI | 성향 맞춤 ETF 제안 | 상품 추천. **매매 습관**은 안 다룸 |
| 한투 안전 투자 알림 | 위험 패턴 경고 | 경고만. **대안(원칙)** 제시 없음 |

**한 줄 차별점**: 기존은 "도구"나 "경고"를 준다. 이 서비스는 **매수 순간에 "내 계획"을 세우게 하고, 그 계획을 지키도록 돕는다.**

## 3. 서비스 흐름 (2쪽 재료) — 단계별로 넣을지 직접 결정
### ① 신청 (Opt-in)
- 하나증권V 간편모드 사용자에게 먼저 제안, 원하는 사람만 켬 (강제 아님 → 거래 방해 논란 최소화)

### ② 매수할 때: "이번 매수는 어떤 매매인가요?"
- [단기] [스윙] [장기] [잘 모르겠어요 → 30초 설명 보기]

### ③ 스타일 설명 카드 (교육) — **비중 축소: 한 줄 요약 + '자세히 보기'로 펼치기**
- 기본 노출은 한 줄: 예) 단기 "며칠 안에 정리하는 매매. 빠른 손절이 핵심" / 스윙 "몇 주 추세를 타는 매매" / 장기 "기업 가치를 보고 오래 가져가는 매매"
- 기획서에서도 2쪽 안에서 2~3줄만 사용 (아래 표는 '자세히 보기' 내용)

| | 단기 | 스윙 | 장기 |
|---|---|---|---|
| 보유 기간 (예시) | 당일~수일 | 수일~수주 | 수개월~수년 |
| 주로 보는 것 | 수급·가격 흐름 | 추세·차트 | 기업 가치·실적 |
| 특징 | 빠른 판단 필요, 하루 종일 볼 수 있어야 | 중간 | 변동을 견디는 인내 |
| 흔한 실수 | 손절 못 하고 버티기 | 추세 꺾여도 보유 | 급락에 공포 매도 |
> ⚠️ 수치·내용은 **예시**. 실제 기획서엔 출처(투자 교육 자료 등) 붙여야 함

### ④ 원칙 예시 → "내 매매 플랜" 만들기
- 전문가들이 흔히 쓰는 원칙을 **예시로** 제시, 숫자는 **손님이 직접** 정함
  - 예) 단기: "손실 ○% 되면 정리", "당일 안에 정리" / 스윙: "추세선 이탈 시 정리", "분할 매수" / 장기: "한 종목 비중 ○% 이하", "실적이 꺾이면 재검토"
- 저장된 플랜 → **기존 자동감시주문 설정을 '제안'** (원클릭, 손님이 선택)

### ⑤ 보유 중: 플랜 지킴이 알림
- 내가 정한 손실선 근접 시 → "**당신이 정한 원칙**: -5%면 정리. 지금 -4.6%예요"
- **스타일 이탈 감지**: 단기로 샀는데 2주째 보유 중 → "단기 매매가 장기 보유로 바뀌고 있어요. 플랜을 다시 볼까요?"
- (선택) **급락장 연결**: 간밤 미국 섹터 급락 시 해당 종목 플랜 리마인드 (이전 아이디어 흡수)

### ⑤-2 ⭐ 물타기 가드 (본인 경험 기반, 2026-11-14 추가)
> 본인 경험: 단기로 들어갔다가 급락하자 **생각 없이 물타기**를 한 적이 있음 → 1쪽 도입부 재료

- **언제 뜨나**: 평가손실 중인 종목에 **추가 매수** 주문을 넣을 때 (특히 처음 플랜이 '단기'였던 종목)
- **무엇을 묻나**: "이번 추가 매수는 **처음 플랜에 있던 분할 매수**인가요, **손실을 메우려는 매수**인가요?"
  - 플랜에 있던 분할 매수 → 그대로 진행 (계획된 매수는 막지 않음)
  - 계획에 없던 매수 → 아래 카드 표시
- **무엇을 보여주나 (내 돈 기준, 사실·계산만)**
  1. **처음 내 계획**: "처음엔 단기, 손실 -3%면 정리하기로 했어요. 지금 -12%예요"
  2. **물타기 후 변화**: 평균 단가 ○○원 → ○○원, 이 종목 비중 30% → 55%
  3. **원금 회복에 필요한 상승률**: -10% → +11.1%, -20% → +25%, -30% → +42.9%, -50% → +100% (수학적 사실)
  4. **추가로 같은 폭 떨어지면**: 손실 금액 -○○만원 → -○○만원
- **선택지 (결정은 손님)**: [플랜을 '스윙/장기'로 바꾸고 진행] [그대로 진행] [취소] [**내일 다시 생각하기** → 다음 날 아침 알림]
- **스타일 이탈 감지(⑤)와 연결**: "단기→물타기→장기 보유"로 굳어지는 흐름을 **물타기 순간**에 끊어줌

### ⑥ 매도 후: 복기
- "원칙을 지켰나요?" 기록 → 월간 **투자습관 리포트** (원칙 준수율, 스타일별 성과)

## 4. 지켜야 할 선 (실현 가능성)
- **증권사가 대신 관리하지 않음**: 자동 매도 강제 X, 모든 결정·숫자는 손님이
- **투자권유 아님**: 특정 종목 매수/매도 의견 X, 일반적 교육 콘텐츠 + 손님 자체 설정
- **피로도**: 신청자만, 알림 빈도 조절, 숙련자는 끄기 가능

## 5. 하나증권 입장에서 좋은 점 (3쪽 재료)
- 손님: 큰 손실 방지, 투자습관 형성, "앱이 나를 챙겨준다"는 신뢰
- 회사: 입문자 이탈 방지(큰 손실 후 떠나는 손님 ↓), 장기 고객 육성, 소비자보호 이미지, 기존 기능(자동감시주문·간편모드·AI 브리핑·하나Q) 재활용 → 개발 부담 ↓
- 측정 지표 후보: 플랜 설정률, 원칙 준수율, 신청자 vs 비신청자 큰 손실 비율, 6개월 잔존율

## 6. 예상 질문 (최종 PT 대비)
- ⭐ **"증권사는 거래 수수료로 버는데, 거래 줄이는 서비스를 왜 하나?"** (가장 날카로운 질문 — 3쪽 '제약 및 고려사항'에 먼저 꺼내기)
  1. **거래를 막는 게 아니라 '계획 없는' 거래만 한 번 멈춤**: 플랜대로의 분할 매수·손절·익절은 오히려 매매로 이어짐
  2. **크게 잃은 입문자는 떠난다** → 떠난 손님의 미래 수수료는 0. 업계에서도 변동성 피로 → 개인 자금 이탈(예금·해외주식) 우려
  3. **수수료 단가는 계속 낮아짐**(무료·인하 경쟁) → 거래 횟수보다 **손님 수·맡긴 자산·오래 남는 것**이 중요
  4. **하나증권 수익 축은 WM**: 상반기 수수료이익 4,986억(+158%)을 WM·S&T가 견인, 전략도 "AI 기반 초개인화 자산관리" → 살아남은 입문자가 **미래의 WM 손님**(연금·ISA·자산관리)
  5. **신뢰·규제 비용**: 불완전판매 제재(2026-10) 등 소비자보호 압력 ↑ → 보호 서비스는 비용이 아니라 리스크 관리
  - 측정 지표로 증명: 신청자 vs 비신청자 **6개월 잔존율·예탁자산 증가율·월 거래 지속 여부**
  - 정직하게 인정: 단기적으로 충동 매매 일부 감소 가능 → 그래서 **신청자 한정 + 파일럿(시범 운영) 후 확대** 제안

## 8. ⭐ 레버리지 모드 (본인 제안, 2026-11-14)
> 본인 경험: 레버리지 사전교육을 **대충 이수**했고, 전문지식·투자역량 없이 거래했다.
> ⚠️ 공모전은 **1인 1개 아이디어** → 별도 서비스가 아니라 **원칙 코치 안의 '특별 모드'**로 통합

### 근거 (2026 실제 상황)
- 2026-05-27 삼성전자·SK하이닉스 **단일종목 레버리지 ETF** 출시 → 거래대금 급증
- 삼성전자 단일종목 레버리지 ETF 7종 평균 수익률 **-33.43%** vs 삼성전자 본주 **-12.04%** (음의 복리 효과)
- 금융투자교육원은 이수자 **이해도 평가·사후 설문 없음**, 교육 효과 분석 보고서 없음 (국회 지적)
- 당국 대응: 기본예탁금 1,000만 → **3,000만원(현금만)** (07-31), 사전교육 **3시간**, **모의거래 5시간** 의무 (08-19), 해외 레버리지 ETP도 기본예탁금 적용 (05-22)
- ⇒ 규제는 "**문턱**"을 높였지만, 문턱을 넘은 뒤 **"내 돈으로 실제 어떻게 되는지"**는 여전히 모름 → 빈틈

### 기능 구성
1. **매수 시 자동으로 '단기' 스타일 지정** + 보유 기간·손절선 플랜 필수 설정
2. **내 계좌 기준 시나리오 카드** (사실·계산만)
   - 예: 계좌 1,000만원 중 500만원 투자 시, 기초자산이 **+10% → -10%** 반복(횡보)하면
     - 본주: 500 → 약 495만원 (-1%)
     - 2배: 500 → 약 480만원 (-4%)
     - 3배: 500 → 약 455만원 (-9%)
   - 상승장 / 횡보장 / 하락장 3가지를 과거 데이터 기반으로 비교 (확정 예측 아님 표시)
   - 실제 사례: 2026년 삼성전자 레버리지 평균 -33% vs 본주 -12%
3. **같은 노출, 다른 방법 비교** (추천 X, 비교만)
   - 본주 500만원 vs 2배 레버리지 250만원(노출은 비슷, 250만원 현금 남음) — 각각 횡보·하락 시 결과
4. **맞는 상황 / 안 맞는 상황** (상품 특성 일반 정보)
   - 맞는 편: 짧은 보유(일~수일), 뚜렷한 방향, 손절선 확정
   - 안 맞는 편: 횡보장·하락장, 장기 보유, **물타기**
5. **내 숫자로 푸는 이해도 확인 3문항** — 기존 교육에 없는 '이해도 평가'를 매수 시점에 보완
6. **보유 중**: 계획한 보유 기간 초과 시 "음의 복리 누적" 알림, 레버리지 종목은 **물타기 가드 강화**
