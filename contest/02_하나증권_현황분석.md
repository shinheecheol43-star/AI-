# 하나증권 현황 분석 (공모전 준비용)

> 2026-11-11 웹 검색 기준. 기사 대부분이 보도자료 기반이라 **회사 측 설명**에 가까움. 실제 사용 경험·이용자 평가는 별도 확인 필요.

## 1. 회사 방향 (경영 전략)
- 강성묵 대표 2026 신년사: "부분적 개선이 아닌 **환골탈태 수준의 변화**", **AI 중심으로 업무 전반 재설계**
- WM(자산관리) 부문: **패밀리오피스 중심 채널 혁신** + **AI 기반 초개인화 자산관리**
- 그 외: 발행어음(단기금융업 인가) 기반 모험자본 공급, STO 등 디지털 자산, 아시아 시장 진출
- 조직: WM·IB·S&T·경영지원 4개 그룹 체제로 개편, 키워드 "손님 신뢰"

## 2. 이미 있는 디지털 서비스 (= "기존과 무엇이 다른가"의 비교 대상)

### 신규 MTS '하나증권V' (2026-09-07 출시)
| 기능 | 내용 |
|---|---|
| AI 브리핑 | 미국 증시 마감 시황 + 주요 종목 등락 배경을 AI가 요약 |
| 리서치 포인트 | 보유 종목 관련 리서치를 선별 제공 |
| ETF MBTI | 보유 종목·투자 성향 기반 ETF 제안 |
| Dual UX | **간편모드(초보·고령층) / 프로모드(전문가)** 3초 전환 |
| 통합잔고 | 국내·해외 주식 한 화면 조회 |
| 차트 | 개인별 커스터마이징 |
| AI 투자 스타일 분석 | 투자자 스타일 분석 서비스 (10월 보도) |
- 수상: 2026 아시아스마트금융대상 MTS 평가 **고객친화 부문 최우수상**

### AI 챗봇 '하나Q' (2026-05-22 출시)
- 생성형 AI, 24시간 365일, 사내 지식 실시간 검색 후 답변 생성
- **상담원·지점 연결 방식은 확인 안 됨** (키움은 '전문 상담원 연결' 버튼 → 채팅 전환 방식)

### 기타
- 핀트 × 하나증권 '하이브리드형 AI투자' AI 자율주행 투자 서비스 (2026-04)
- 푸투증권과 외국인 통합계좌 (2026-07)
- 상품·서비스 자문단 2기 출범 (2026-04, 금융소비자 권익 보호)

## 3. 오프라인 채널
- 초고액자산가 전담센터: 센터필드 W(플래그십), **THE H1 W**(현대백화점 목동점, 2026-06)
- 업계 흐름: 10대 증권사 지점 수 400곳 아래 전망 → 단순 창구 점포는 줄이고 **거점형 WM 대형 점포**로
- 하나증권 자체 지점 수 변화는 미확인

## 4. 관찰 (가설 — 검증 필요)
1. **방금 큰 투자를 했다**: 하나Q(5월) → 하나증권V(9월) → 공모전(11월). 새 앱과 AI 서비스를 내놓은 직후라, **이걸 더 잘 쓰게 만들 아이디어**나 **아직 빈 곳**을 찾고 싶을 가능성이 높음.
2. **간편모드는 '화면을 단순하게' 한 것**: 처음 투자하는 사람이 차트·지표를 **이해하도록 돕는 것**까지 해결했는지는 불명확 → 주제 1의 기회 영역.
3. **오프라인은 고액자산가 중심으로 가고 있음**: 20대·투자 입문자에게 지점은 멀다. 앱(대중) ↔ 지점(VVIP)이 따로 노는 구조라면 **주제 2의 빈틈**.
4. **챗봇 → 사람 연결이 안 보임**: AI가 못 푸는 질문을 지점·전문가로 넘기는 다리가 있는지 확인 필요 (주제 2와 연결).
5. **보안·사기 예방은 하나은행 쪽이 더 앞서 보임** (하나원큐 실시간 스미싱 확인 등) → 증권 고유의 위험(리딩방, 급등락 위험 이해 등)에 특화된 안심 서비스는 주제 3의 기회.
