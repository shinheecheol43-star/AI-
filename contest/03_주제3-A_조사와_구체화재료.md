# 주제 3-A "이해하고 사는 주문" — 기존 기능 조사 & 구체화 재료

> 2026-11-11 웹 검색 기준. ⚠️ 하나증권 앱을 직접 확인하지 않았으므로 "없다"가 아니라 **"기사로는 확인되지 않음"**.
> 이 문서는 **재료와 선택지**입니다. 어떤 조합으로 갈지는 직접 결정 → 기획서 핵심 발상은 본인 작성.

## 1. 지금 있는 것 (업계)
| 회사 | 서비스 | 내용 | 한계 (빈틈) |
|---|---|---|---|
| 한국투자증권 | 안전 투자 알림 (2025-11, **금융당국 방침**에 따라) | 단기매매·집중투자·신용거래 등 위험 패턴 감지 시 하루 1~2회 경고 문구 | **일반적인 경고 문구** → "그래서 내 돈이 얼마나 위험한데?"는 안 알려줌 |
| 한국투자증권 | AI 종목 분석 '지금 종목은' (2026-06) | 종목별 흐름·리스크 요인 | 종목 중심, **내 주문·내 계좌 기준 아님** |
| 신한투자증권 | AI 신용공여 지킴이 | 신용 종목 관리 | 신용거래 한정 |
| 공통 | 시장경보제도 표시 | 거래소 지정 투자주의·경고·위험 종목 표시 | 용어만 표시, 초보는 의미를 모름 |
| 하나증권 | 하나증권V 간편모드, AI 브리핑, 하나Q | 화면 단순화, 시황 요약, 챗봇 | **매수 직전 위험 안내 기능은 기사로 확인 안 됨** |

### 시사점
- 당국 방침으로 "경고"는 업계 기본이 되는 중 → **경고를 띄우는 것 자체로는 참신성 없음**
- 빈틈은 **"경고 → 이해"**: 일반 문구가 아니라 **내 주문 금액·내 계좌 기준으로 체감되게** 보여주는 것
- 업계에서 AI 종목 분석이 **'투자권유' 경계선** 논란 → 사실·수치만 보여주고 매수/매도 의견은 주지 않는 설계 필요

## 2. 규제 맥락
- 금소법: 적합성 원칙(부적합 상품 권유 금지), 설명의무, 위반 시 과태료
- 온라인 판매는 한 방향 소통이라 **설명의무가 가장 취약** (금융소비자보호재단 평가: 설명의무 평균 11.6/43.4점)
- 하나증권 2026-10 리테일채권 불완전판매 제재 → 회사가 실제로 아픈 지점
- (확인 필요) 투자자가 스스로 주문하는 일반 주식 매매에는 적합성 원칙이 직접 적용되지 않는 경우가 많음 → **법 의무 이상을 하는 '자발적 보호'**라는 포지션 가능

## 3. 구체화 블록 — 각 블록에서 선택하기

### 블록 A. 언제 뜨나 (트리거) — 1~3개 선택
- A1. 시장경보 종목(투자주의·경고·위험) 매수 시
- A2. 단기 급등 종목 (예: 최근 5일 +30% 이상) 매수 시
- A3. 신용·미수로 매수 시
- A4. 이번 주문 후 한 종목이 내 계좌의 큰 비중 (예: 50%↑) 차지 시
- A5. 레버리지·인버스 ETF, 해외 레버리지 등 고위험 상품 첫 매수 시
- A6. 투자 경험이 적은 손님(가입 초기, 간편모드 사용자) 우선 적용

### 블록 B. 무엇을 보여주나 (위험 미리보기 카드) — 핵심 차별점
- B1. **내 돈 기준 변동폭**: "최근 한 달 이 종목의 하루 최대 하락폭만큼 움직이면 내 주문 100만원 → 약 ○○만원"
- B2. **내 계좌 기준 비중**: "이 주문 후 전체 자산의 ○○%가 한 종목에 몰려요"
- B3. **위험 신호의 이유 (AI 요약, 사실만)**: "투자경고 지정 사유: 단기 급등", "최근 거래량 평소의 ○배"
- B4. **비슷한 상황의 과거 사례 (통계)**: "단기 급등 후 투자경고 지정된 종목들의 이후 한 달 평균 흐름" — ⚠️ 데이터 정확성·오해 소지 검토 필요
- 원칙: **매수/매도 의견은 절대 안 줌** → 판단은 손님 (그룹 원칙 "AI는 보조, 판단은 사람")

### 블록 C. 어떻게 확인하나 (이해 확인)
- C1. 카드만 보여주고 바로 주문 가능 (가벼움)
- C2. 체크 1개: "이 주문으로 하루에 최대 ○○만원까지 변할 수 있다는 걸 확인했어요"
- C3. 고위험 상품 첫 매수 시에만 3문항 미니 퀴즈 (적정성 확인의 디지털화)
- 피로도 관리: 같은 종목은 하루 1회, 숙련자는 '간단히 보기' 선택 가능

### 블록 D. 산 다음엔 (사후 케어) — 선택
- D1. 매수 시 **"내 원칙 메모"** 작성 (예: "-10%면 다시 생각") → 해당 수준 도달 시 내 메모를 알림으로 보여줌 (실시간 대응 어려움 해결)
- D2. 큰 변동 시 하나Q/디지털 PB 상담 연결 버튼 (주제 2 요소 살짝)
- D3. 월 1회 "내 위험 리포트": 이번 달 위험 신호 몇 번, 그때 내 선택과 결과

### 블록 E. 하나증권 자산과 연결 (실현 가능성 근거)
- 하나증권V 간편모드 기본 탑재 / AI 브리핑의 요약 기술 재활용 / 하나Q와 연계
- 시장경보·시세 데이터는 이미 보유 → 신규 데이터 확보 부담 적음

## 4. 기대효과 지표 후보
- 손님: 위험 인지 후 주문 수정·취소 비율, 이해 확인 통과율, 큰 손실 경험 비율 감소
- 회사: 민원·분쟁 감소, 불완전판매 리스크 감소, 신뢰도·재방문(MAU) 상승, 소비자보호 평가 개선

## 5. 예상 반론 & 대응 (3쪽 '제약 및 고려사항' 재료)
| 반론 | 대응 방향 |
|---|---|
| 주문이 귀찮아져서 거래 줄면 회사 수익 감소? | 트리거 한정 + 하루 1회 + 숙련자 간단 보기 / 장기적으로 신뢰·이탈 방지 |
| AI 설명이 투자권유로 볼 수 있음 | 사실·수치만 제공, 의견 금지, 컴플라이언스 검수 문구 |
| 과거 변동폭으로 미래 위험을 다 설명 못 함 | "과거 기준 참고치" 명시 |
| 이미 경고 팝업 있는데? | 일반 문구 → **내 돈·내 계좌 기준 체감형**이 차이 |

## 6. ⭐ 본인 아이디어 (2026-11-11): "섹터 급락 충격 안내" — 미국 → 한국 → 내 계좌
> 계기: 2026-11-05 미국 필라델피아 반도체지수 장중 -8%대, 나스닥 -3.7%대 → 11-06 삼성전자·SK하이닉스 프리마켓 급락

### 흐름 (본인 제안)
1. **간밤 충격**: "나스닥 -5% 급락, 주요 하락 섹터는 반도체"
2. **하락 이유**: AI가 뉴스·공시 기반 요약
3. **한국 연관성**: 어떤 한국 섹터·종목과 연결될 수 있는지
4. **한국 섹터 현황 + 투자주의**: 시장경보 지정 현황 등

### 이미 있는 것과 겹치는 부분 (차별화 필요)
| 서비스 | 하는 일 | 내 아이디어와 차이 후보 |
|---|---|---|
| 하나증권V AI 브리핑 | 미국 마감 시황 + 종목 등락 이유 요약 | 미국에서 끝남. **한국 연결·내 계좌·보호 행동**이 없음(기사 기준) |
| 신한 '오늘 내 주식은' | 보유·관심 종목 이슈와 미국 공시 정리 | 종목 단위 정보 제공. **섹터 충격의 전이 + 보호** 관점 아님 |
| 미래에셋 'AI이슈체크' | 미국주식 급등락 알림 | 미국 종목 한정 |

### 차별화 포인트 후보 (선택)
- 정보 → **보호**: "알려주기"에서 끝나지 않고 **내 계좌 노출도**("내 자산의 ○○%가 반도체 관련") + **충동 매매 방지**로 연결
- **타이밍**: 한국 장 시작 전 (예: 08:00 프리마켓 전)에, **급락 기준 넘을 때만** 발송 → 알림 피로 방지
- **3-A 결합**: 장 초반 패닉 매도·물타기 주문 시 "간밤 충격 카드" + 내 돈 기준 변동폭 다시 보여주기
- **내 원칙 메모**와 연결: "반도체 -10%면 다시 생각" 메모를 이 순간 보여주기

### 결정할 것
- [ ] 알림 발송 기준 (예: 나스닥 -3%↑ 또는 미국 섹터 -5%↑)
- [ ] 발송 시점 (장 시작 전 몇 시)
- [ ] 대상 (해당 섹터 보유자만? 관심종목 등록자까지?)
- [ ] 카드 이후 행동 (정보만 / 주문 시 재안내 / 원칙 메모 / PB 상담 연결)
- [ ] 서비스 이름

### 주의점
- "사세요/파세요" 금지, 사실·수치·연관성만 (투자권유 경계)
- 연관성 분석은 "과거 동조 경향" 수준으로 표현, 확정적 예측 금지
- AI 요약 오류 가능성 → 출처 링크 표시
